# 🎾 테니스 작전판 (Tennis Tactics Board)

브라우저에서 바로 쓰는 2.5D 테니스 작전판입니다. 선수와 공을 배치해 장면을 저장하고, 저장한 장면들을 이어서 하나의 플레이로 재생하거나 영상으로 저장할 수 있습니다.

**▶ 바로 사용하기: https://chiseongan.github.io/tennis-tactics-board/**

## 기능
- 2.5D 코트 (하드 / 클레이 / 잔디), 단식·복식
- 선수·공 드래그 배치, 장면(프레임) 저장
- 달리기·스윙 애니메이션 (서브, 포핸드, 백핸드, 발리, 스매시 자동 판별)
- 공 궤적(드라이브 / 보통 / 로브)과 장면별 이동 시간·메모
- 전체 플레이 재생, 영상(MP4/WebM)으로 녹화·다운로드
- 브라우저 자동 저장, 이름 붙여 저장, JSON 파일 내보내기/가져오기

## 단축키
| 키 | 동작 |
|---|---|
| `Space` | 현재 배치를 새 장면으로 저장 |
| `U` | 선택한 장면 덮어쓰기 |
| `←` `→` | 이전 / 다음 장면 |
| `Del` | 선택한 장면 삭제 |
| `Enter` | 재생 / 정지 |
| `R` | 영상으로 녹화 |
| `Esc` | 재생·녹화 중지 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |

## 사용 팁
- 공을 선수 근처(2m 이내)에 두면 그 선수가 치는 장면, 빈 곳에 두면 바운드 지점이 됩니다.
- 영상 녹화는 Chrome 또는 Edge를 권장합니다. 녹화 중에는 탭을 띄워 두세요.

별도 설치 없이 `index.html` 하나로 동작합니다.
